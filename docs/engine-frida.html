Frida Engine

5 cooperative dump strategies (including FART-style ClassLinker::DefineClass) paired with 7 unified pre-resume anti-detection bypasses, jailed-Gadget USB detection, and safe output filename sanitization.

5 种协同脱壳策略（含 FART 风格 ClassLinker::DefineClass 类注册挂钩）+ 7 项 resume 前同步生效的统一反检测绕过，具备越狱/Gadget USB 预检与安全文件名清洗。

5 STRATEGIES · 7 ANTI-DETECT
USB Preflight → Spawn → 7 Anti-Detect (Pre-Resume) → Resume → 5 Strategies (S1–S5) → Sanitized Save → 10-Step Repair

5 Cooperative Strategies5 种协同脱壳策略

  • S1: Polling memory scan with strict DEX header validation轮询内存扫描 + 严格 DEX 头部校验
  • S2: DexFile::OpenCommon / OpenMemory hooks加载挂钩
  • S3: ClassLoader mCookie native pointer sweepClassLoader mCookie 指针遍历
  • S4: dlopen / android_dlopen_ext decrypted SO dump解密 SO 同步提取
  • S5: art::ClassLinker::DefineClass (FART-style class registration capture)（FART 风格类注册精准捕获）

7 Unified Anti-Detect Hooks7 项统一反检测绕过

  • 1. /proc/self/maps filtering • 2. sigaction watchdog blocking1. /proc/self/maps 过滤 • 2. sigaction 看门狗信号拦截
  • 3. prctl(PR_SET_NAME) thread masquerade • 4. Port 27042 hiding3. prctl 线程名伪装 • 4. 27042 端口扫描隐藏
  • 5. TracerPid=0 spoof • 6. Frida class hiding • 7. gettimeofday timing5. TracerPid=0 伪造 • 6. Frida 类名隐藏 • 7. 时间差检测缓解
  • Shared across Frida Engine & Active Invocation (disable with --no-anti-detect)Frida 引擎与主动调用共用同一实现（可通过 --no-anti-detect 关闭）
