UNPACK Studio

A zero-CDN, bilingual (中/EN), dark/light Android reverse-engineering workbench backed by modular Flask Blueprints (src/unpack/studio/), persistent SQLite workspaces, and a built-in 7-provider AI engine.

零外部 CDN 依赖、支持中英双语与深浅色主题的 Android 逆向分析工作台，底层基于模块化 Flask Blueprints（src/unpack/studio/）、SQLite 持久化工作区与内置 7 大模型 AI 引擎构建。

Everything in One Cohesive Workspace全链路逆向任务一站式协同

1. Samples & Intake

VAULT

Drag-and-drop APK/DEX intake, SHA-256 deduplication, local library browser, automatic SHA-256 file relocation after folder moves, and explicit offline/snapshot-only indicators.

支持拖拽上传 APK/DEX、SHA-256 去重缓存、本地样本库导入、目录迁移后的 SHA-256 自动重定位，以及离线快照模式显式徽章与重挂载提示。

2. Scan & Intelligence

24 PACKERS

6-dimension packer breakdown, confidence bars, protection-level badge, version detection, and one-click AI packer strategy briefing.

可视化呈现 6 维壳识别证据、置信度评分、保护等级与版本指纹，支持一键唤起内置 AI 生成脱壳与绕过策略简报。

3. APK & DEX Inspector

3-PANE

Full Manifest, signing certificate, permission risk analysis, plus a live 3-pane DEX browser: class tree, method table, Dalvik bytecode disassembler, strings & IOC explorer.

涵盖 Manifest、签名证书与权限风险解析，并提供三栏式 DEX 浏览器：类树导航、方法列表、Dalvik 反汇编视图与字符串/IOC 检索。

4. VMP & Native Studio

ELF + VMP

Method-level classification (normal / NOP / VMP-stub) with search filtering, paired with ELF SO inspection for anti-debug, VMP, DEX2C, and crypto indicators.

方法级 VMP 分类（normal / NOP / VMP-stub）与实时过滤，联动原生 ELF SO 分析，高亮反调试、VMP、DEX2C 与加解密风险标记。

5. Repair & Verify Lab

DIFF VIEW

Run the 10-step DEX repair pipeline with before/after header & metric diffs, code coverage scoring, FART export, and APK repacking.

执行 10 步 DEX 修复并展示修复前后头部/指标 Diff，联动覆盖率评分、FART 格式导出与可分析 APK 一键重打包。

6. Pipeline Studio

6-STAGE

Guided 6-stage planner with live Environment Doctor preflight. Run zero-device offline pipelines or connected-device Memory/Frida/eBPF unpacking with live SSE job logs.

6 阶段引导式流水线规划器，联动 Environment Doctor 预检；支持无设备离线模式或真机三引擎模式，通过 SSE 实时推送任务日志。

7. Reports & Export

SARIF 2.1.0

Generate and preview commercial audit reports in sandboxed HTML5 (sandbox=""), Markdown, JSON, and SARIF 2.1.0 for GitHub Code Scanning / CI pipelines.

支持在无脚本安全沙箱（sandbox=""）内即时预览并导出 HTML5、Markdown、JSON 及 SARIF 2.1.0 审计报告，直接对接 CI 安全门禁。

Command Palette & Accessibility

⌘K

Keyboard-first ⌘K command palette with ArrowUp/ArrowDown navigation, in-app modals (zero native window.prompt()), :focus-visible rings, and prefers-reduced-motion support.

键盘优先的 ⌘K 命令面板（支持方向键导航）、内建弹窗替代原生 window.prompt()、完整的 :focus-visible 焦点环与减弱动效适配。

Environment Doctor Modal

LIVE CHECK

Real-time check of ADB, rooted devices, Frida server, eBPF/bpftrace, and optional RE Python packages directly from the sidebar status dot.

从侧边栏状态指示灯随时检视 ADB、Root 设备、Frida Server、eBPF/bpftrace 与 Python 逆向依赖的就绪度。

Persistent Workspaces持久化 SQLite 工作区

Auditable Case Management可归档、可迁移的样本工程管理

Every scan, DEX inspection, pipeline run, and AI briefing can be persisted in local SQLite workspaces (~/.unpack/) and exchanged across teams as self-contained JSON bundles.

所有扫描结论、DEX 检视、流水线记录与 AI 研判均沉淀至本地 SQLite 工作区（~/.unpack/），支持导出/导入完整 JSON 快照包在团队间流转。

  • Atomic transaction import/export via JSON bundlesJSON 快照包原子事务导入/导出
  • SHA-256 auto-relocation when local APK directories move本地 APK 目录移动后按 SHA-256 自动重定位
  • Snapshot-only read-only fallback when binary is detached原始样本缺失时自动降级为快照只读模式
  • Shared store between CLI (unpack workspace) and StudioCLI（unpack workspace）与 Studio 实时共享同一数据库
Backend Architecture & Security后端模块化架构与安全加固

Flask Blueprints, API v1 & Production HardeningFlask 蓝图拆分、API v1 与生产级安全基线

Modular src/unpack/studio/ Layout模块化 src/unpack/studio/ 结构

  • studio/routes/system.py — /api/v1/health, diagnostics, doctor, config
  • studio/routes/samples.py — intake, upload, local library, auto-relocate
  • studio/routes/analysis.py — scan, inspect, DEX browser, disasm, VMP, XRef
  • studio/routes/repair_export.py — verify, 10-step repair diff, FART export, repack, reports
  • studio/routes/pipeline.py — 6-stage plan, offline & device job runner, SSE stream
  • studio/routes/workspaces.py & ai.py — SQLite workspace CRUD & 7-provider AI endpoints
  • web.py — thin backward-compatible facade (create_app, JobManager, main)

Security & Reliability Hardening安全响应头与资源边界保护

  • Script-free report iframe preview (sandbox="") & XSS-safe Markdown rendering报告预览采用无脚本沙箱（sandbox=""）与 XSS 安全的 Markdown 渲染
  • Bounded artifact/lock LRU eviction & capped ThreadPoolExecutor background jobs有界 LRU 产物/锁缓存驱逐与限流 ThreadPoolExecutor 异步任务池
  • Unified api_error() envelope, strict input allowlists, and enriched /api/v1/health telemetry统一 api_error() 错误信封、严格入参白名单及增强型 /api/v1/health 健康遥测
