eBPF Engine

kernel-level uprobe on libart.so via bpftrace — stealthiest approach

How It Works

  • • eBPF uprobe attaches to libart.so in kernel space
  • • When ART loads a DEX, uprobe captures base+size
  • • dump_helper.sh reads DEX via /proc/pid/mem
  • • Symbol OR offset-based probing for flexibility

Requirements

  • • Root + kernel >= 5.4 + CONFIG_BPF + CONFIG_UPROBES
  • • bpftrace static binary (~176MB) on device
  • • Symbols in available_filter_functions (or offset fallback)
  • • Not all Android kernels expose libart symbols

Known Issues

  • • Android 13 kernel 5.10: libart symbols not probeable
  • • Offset fallback needs exact ELF VALUE from readelf
  • • bpftrace startup is slow (~5-8s to compile BPF)
  • • Passive: can't trigger function-extracted method decrypt
