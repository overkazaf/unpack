unpack doctorPREFLIGHT

Check Python dependencies, RE tools, connected ADB devices, root access, and engine readiness.

检查 Python 依赖、逆向工具链、ADB 设备连接、Root 权限与三引擎就绪状态。

unpack doctor [--device SERIAL] [--no-devices] [--format json]
--json--format--device--no-devices--lang
unpack scanCORE

Identify packer vendor (24 signatures), version, confidence breakdown, and protection level without a device.

免设备静态识别 24 家壳厂商、版本号、6 维置信度分布与保护等级，支持批量扫描。

unpack scan app.apk [-v] [-r] [--batch] [-j out.json]
-v / --verbose-r / --report--batch-j / --json--format
unpack inspectSTATIC RE

Deep static inspection of an APK (manifest, signing cert, native ELF libs, permissions) or DEX (classes, methods, Dalvik disassembly).

深度静态检视 APK（Manifest、签名、原生 ELF、权限）或 DEX（类表、方法、Dalvik 反汇编）。

unpack inspect app.apk [--classes] [--methods CLASS] [--disasm METHOD] [--permissions]
--classes--methods CLASS--disasm METHOD--permissions--json PATH
unpack dumpUNPACK

Full automated flow: scan → dispatch engine → dump DEX/SO → optional --deep active invoke → 10-step repair → verify.

全自动脱壳流程：壳识别 → 策略路由 → 提取 DEX/SO → 可选 --deep 主动调用 → 10 步修复 → 质量校验。

unpack dump app.apk [-o ./out] [-e memory|frida|ebpf] [--deep] [--report-html report.html]
-e / --engine-d / --device-t / --timeout--deep--no-anti-detect--skip-repair--report-html PATH--explain
unpack repair10-STEP

Run the 10-step DEX repair pipeline on dumped DEX files (CDEX, header, sections, truncation, map, debug_info, NOP, checksum).

对 dump 产出的 DEX 文件执行 10 步修复流水线（CDEX、头部、越界段、截断恢复、校验和重算等）。

unpack repair ./unpacked/ [--in-place] [--json out.json]
--in-place--json--format--out
unpack verifyVERIFY

Verify DEX structural integrity, checksums, class/method coverage, and remaining NOP-only methods.

校验 DEX 结构完整性、校验和、类/方法覆盖率以及残留的 NOP 函数抽取方法数。

unpack verify ./unpacked/ [--json verify.json]
--json--format--out
unpack vmpVMP

Classify DEX methods into normal, NOP-extracted, and VMP-stub categories to focus manual RE effort.

按方法粒度分类标注 normal / NOP / VMP-stub，快速锁定虚拟化保护焦点方法。

unpack vmp ./unpacked/ [-j vmp.json]
-j / --json--format--out
unpack xrefXREF

Build a cross-reference index across strings, method calls, reflection targets, and field accesses with keyword search.

构建字符串、方法调用、反射目标与字段引用的交叉引用索引，支持关键字过滤检索。

unpack xref ./unpacked/ [--search "decrypt"] [-j xref.json]
--search-j / --json--format--out
unpack repackRECONSTRUCT

Combine original APK resources/manifest with unpacked repaired DEX files into a clean APK for jadx/JEB.

将原始 APK 资源/清单与脱壳修复后的 DEX 重打包为可直接拖入 jadx / JEB 的可分析 APK。

unpack repack app.apk ./unpacked/ -o ./repacked
-o / --output--json
unpack reassembleRECONSTRUCT

Map dumped DEX classes back onto the original APK multi-DEX layout and numbering.

将散落的脱壳 DEX 按类分布映射回原始 APK 的 multi-DEX 编号布局。

unpack reassemble app.apk ./unpacked/ [-j map.json]
-j / --json
unpack exportEXPORT

Export dumped DEX artifacts into FART-compatible format (fart.bin + fart.txt) for downstream tooling.

将脱壳产物导出为兼容 FART 生态工具的 fart.bin 与 fart.txt 格式。

unpack export ./unpacked/ -f fart [-o ./fart_out]
-f / --format-o / --output--json
unpack rescanINCREMENTAL

Frida-free incremental memory re-scan: exercise exported app components across rounds to trigger lazy method decryption.

免 Frida 增量式重扫：多轮触发 App 组件执行以唤醒按需解密方法并回填增量 DEX。

unpack rescan app.apk ./unpacked/ -r 5 [-d SERIAL]
-r / --rounds-d / --device--json
unpack reportAUDIT

Generate a commercial security & unpacking audit report in HTML5, Markdown, JSON, or SARIF 2.1.0.

生成商业级安全与脱壳审计报告，支持 HTML5、Markdown、JSON 与 SARIF 2.1.0 标准格式。

unpack report ./unpacked/ --apk app.apk --format sarif --vmp --xref -o audit.sarif
--apk--format html|md|json|sarif--out--title--vmp--xref
unpack pipelineGUIDED

Guided 6-stage pipeline planner & runner with live preflight blueprint and zero-device offline or device execution.

6 阶段引导式流水线规划与执行器，支持实时预检蓝图预览、零设备离线执行与真机全流程执行。

unpack pipeline app.apk --mode offline --execute
--mode offline|device--execute--deep--repack--report-html--explain
unpack guideWIZARD

Interactive onboarding wizard: inspect environment readiness, pick an analysis goal, preview commands, and run.

交互式新手向导：检测环境状态、选择分析场景、预览命令蓝图并一键执行。

unpack guide [--scenario SCENARIO] [--target app.apk] [--execute]
--scenario--target--non-interactive--execute
unpack wizardALIAS

Alias for unpack guide — interactive step-by-step onboarding wizard.

unpack guide 的快捷别名 —— 交互式分步引导向导。

unpack wizard [--target app.apk] [--lang zh]
--scenario--target--non-interactive--execute
unpack analyzePIPE LLM

Emit a prompt-wrapped technical scan dossier designed for Unix piping into claude -p or Codex.

输出带分析提示词的纯文本扫描档案，专为管道对接 claude -p 或 Codex 打造。

unpack analyze app.apk [--prompt "..."] | claude -p
--prompt

Structured Output Examples结构化输出示例

# Generate SARIF 2.1.0 for GitHub Code Scanning
unpack report ./unpacked/ \
  --apk app.apk \
  --format sarif \
  --vmp --xref \
  --out unpack-audit.sarif

# Machine-readable batch scan across a release folder
unpack --quiet --log-level WARNING scan ./apks/ --batch --json batch.json

# Pipe scan dossier into Claude CLI
unpack analyze app.apk --prompt "Summarize anti-debug hooks & unpack order" | claude -p
