6-dimension weighted scoring (SO, Manifest, Assets, DEX classes, Certs, small-DEX heuristic) with version fingerprinting (360 v1–v4, Legu v1–v3) and protection-level classification.

3x

3-Engine Smart Dispatcher三引擎智能路由调度

Runtime /proc behavioral fingerprinting routes targets across Memory (zero-injection + multi-PID), Frida (5 strategies + 7 anti-detect hooks), and eBPF (APEX libdexfile.so uprobes) with automatic fallback.

基于保护等级与运行时行为指纹在 Memory（零注入 + 多进程）、Frida（5 策略 + 7 项反检测）与 eBPF（APEX libdexfile.so 内核探针）之间自动调度并支持失败降级。

自动完成 CDEX 转换、Magic/Size 修正、Section 越界清零、截断恢复、Map/Alignment/debug_info 校验、NOP 标记与 SHA-1/Adler32 重算，直接兼容 jadx / JEB / baksmali。

Quick Start快速上手

Install & Run in 60 Seconds60 秒完成安装与全流程运行

# 1. Install (core + Studio web UI + static analysis + Frida)
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[all]"

# 2. Environment preflight & guided wizard
unpack doctor                                  # verify ADB, root, Frida, eBPF, RE deps
unpack guide                                   # interactive onboarding wizard

# 3. Static scan, deep inspection & zero-device offline pipeline
unpack scan app.apk -v                         # 24 packers, version & protection level
unpack inspect app.apk                         # manifest, signing, native ELF, DEX summary
unpack pipeline app.apk --mode offline --execute

# 4. Live device unpacking, 10-step repair & audit reporting
unpack dump app.apk --deep --report-html report.html       # scan -> dispatch -> dump -> repair -> verify
unpack report ./unpacked/ --apk app.apk --format sarif -o audit.sarif

# 5. Built-in Multi-Provider AI & Persistent Workspaces
unpack ai config --provider deepseek --model deepseek-chat --api-key sk-...
unpack ai analyze app.apk --save-workspace default
unpack workspace list

# 6. Launch UNPACK Studio (7-view commercial Web workbench)
unpack web --port 8080
