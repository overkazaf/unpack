Memory Engine

host-side /proc/pid/mem reader — no injection, invisible to anti-frida

Why It Works

  • • No process injection = invisible to all anti-frida
  • • Root reads /proc/pid/mem directly (no ptrace needed)
  • • VDEX-aware: extracts DEX from Android 8+ containers
  • • Host-side Python avoids 32-bit shell integer overflow

Tested Results

  • • NetEase Cloud Music (NetEase Shield v2)
  • • 18 DEX files, 150MB total, 19.6 seconds
  • • 327,660 classes, 1.86M methods
  • • 96.2% code coverage after repair

Limitations

  • • Requires root (su) for /proc/pid/mem access
  • • Only dumps DEX already in memory (post-unpack)
  • • Function-extracted methods remain NOP-filled
  • • Large apps (150MB+) need ~20s for full dump
