Memory Engine

Host-side /proc/pid/mem reader with multi-process child enumeration, VDEX/OAT/CDEX container extraction, and 64KB sliding DEX-in-DEX scanning — zero injection, immune to anti-Frida.

Host 侧解析 /proc/pid/maps 并直读 /proc/pid/mem，支持多进程子进程枚举、VDEX/OAT/CDEX 容器提取与 64KB 滑动窗口 DEX-in-DEX 扫描 —— 零注入，对 anti-Frida 完全免疫。

VERIFIED · ZERO INJECTION
Smart Wait → Multi-PID Enum → Maps Filter → Batch Probe → VDEX/OAT/CDEX + Sliding Scan → 4KB Block Dump → 10-Step Repair

Key Advantages核心优势

  • Zero process injection — anti-Frida & ptrace checks never trigger零进程注入 —— anti-Frida 与反调试检测完全无感
  • Multi-process child enumeration defeats multi-PID packers自动枚举子进程，有效对抗多进程守护壳
  • VDEX, OAT (Android 5–7), CDEX & 64KB sliding DEX-in-DEX support全面支持 VDEX、OAT（Android 5–7）、CDEX 与匿名区滑动扫描

Verified Production Results真机实测表现

  • NetEase Cloud Music (NetEase Shield v2): 18 DEX, 150MB, 19.6s, 96.2% coverage网易云音乐（网易易盾 v2）：18 个 DEX，150MB，19.6s，96.2% 覆盖率
  • Kugou Music (164MB): 31 DEX dumped in 33.7s, 31/31 verify PASS酷狗音乐（164MB）：31 个 DEX，33.7s，31/31 验证通过
  • Pairs with --deep Frida-free App Exerciser + unpack rescan可配合 --deep 免 Frida 交互触发器与 unpack rescan 增量重扫

Requirements & Usage前提条件与用法

  • Requires rooted Android device (su access to /proc/pid/mem)需要已 Root 的 Android 设备（读取 /proc/pid/mem）
  • Captures DEX files already decrypted into process memory仅提取已解密加载到内存中的 DEX
  • unpack dump app.apk -e memory [--deep]
